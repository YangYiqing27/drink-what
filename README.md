# 喝点什么

免费的饮水记录网页应用，适配手机和电脑。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。生产构建使用 `npm run build`。

## 功能

- 记录水、茶、咖啡、奶茶、奶 / 植物奶、果汁、气泡 / 碳酸等饮品。
- 按“大类 → 品牌 → 饮品名称”记录；品牌和品牌下的饮品名称都由用户自己添加，不预置具体内容。
- 选择常用容量或输入自定义容量，记录日期、时间、备注。
- 记录本杯咖啡因（mg）与热量（kcal）；自定义品牌可设置每 100 ml 的数值，选择时按容量换算，可手动覆盖。
- 未填写的营养数值保留为未知，统计展示已填写杯数，不把未知值当作零。
- 调整每日目标，日历合并历史记录与统计，每个日期显示具体饮品及容量，点击查看当日明细。
- 删除记录，删除后可在提示中撤销。
- 导出全部记录为 UTF-8 CSV，包括大类、品牌、容量、咖啡因与热量，可用 Excel 打开。

记录保存在当前浏览器的 localStorage 中。旧版记录自动迁移保留；原有大类记录不会被猜测成某个细分品种。清理浏览器数据会删除记录，请按需导出备份。暂未提供跨设备同步、系统通知和原生应用安装包。统计以实际饮用容量相加，不折算补水效率。内置品种不预填咖啡因与热量，因为品牌、配方、糖量与浓度不同，数值由用户填写。

## iOS 原生版本

原生 SwiftUI 工程位于 `ios/DrinkWhatApp.xcodeproj`。打开后在 Xcode 的 `Signing & Capabilities` 中选择 Apple Developer Team，再选择 iPhone 模拟器或真机运行。详见 `ios/README.md`。
